description_en=S57Manager is a QGIS plugin dedicated to the import, management and display of marine ENC (S-57) data.It allows automatic import of ENC files (.000) into a GeoPackage or PostGIS database, thematic layer organization, predefined styling and scale-based visibility management.The plugin also includes a NOAA module to browse the official ENC catalog, filter cells by purpose, scale and map extent, and download and import them directly into QGIS.S57Manager supports multiple languages (FR/EN/ES/PT) and provides a unified interface for ENC-related tools.
