# Changelog  
Toutes les modifications notables du plugin **S57Manager** sont documentées ici.  

Le format est basé sur [Keep a Changelog](https://keepachangelog.com/fr/1.0.0/)  
et ce projet suit approximativement le versionnage sémantique (SemVer).  

## [1.0.0] - 2025-11-27  

### Ajouté
- Première version publiée sur le dépôt QGIS.  


## [1.0.1] - 2025-11-27    

### Ajouté
- Dans le dialogue Afficher couches S57, ajout de l'option "Limiter au secteur affiché (chargement plus rapide)"  

### Corrigé
- Impossible d'installer les styles ERREUR: paramètre de configuration "transaction_timeout" non reconnu pour PostgreSQL version < 14
